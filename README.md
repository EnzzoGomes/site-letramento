## Funcionalidades

- Perfis de aluno e de administrador
- Cursos organizados em canais, módulos e aulas em vídeo (YouTube)
- Quizzes com resultado e certificado de conclusão
- Acompanhamento de progresso e opção de continuar assistindo
- Painel para gerenciar o conteúdo

## Arquitetura

Aplicação de página única em `index.html`. Os dados ficam no `localStorage` do navegador.

> Protótipo sem back-end. As contas incluídas no código são fictícias e servem apenas para demonstração. Uma versão em produção precisa de autenticação no servidor e de banco de dados.

## Como rodar

Abra `index.html` no navegador.
